One line, spoken by the Moon itself, answering everyone who has stared at it, wished on it, howled at it, and made it 3 a.m. promises for billions of years. The Moon's comeback: you only love it from 384,400 km away — up close it's dust and craters, so enjoy the view and keep your promises down there.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (UTF-8, one line, 1–240 characters) and verifies it byte-for-byte.
